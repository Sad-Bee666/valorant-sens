## 它解决什么问题

网上绝大多数「eDPI 计算器」只做单位换算，并不知道你的手能移动多远。这个工具反过来做：

1. **先量身体条件**：满腕程 W —— 手腕不抬鼠时能推动的最大距离；
2. **再测瞄准能力**：四项测试，全部悬停触发，不需要点击；
3. **最后用物理约束卡死结果**：推荐值必须满足「一次满腕程即可覆盖全屏」，否则自动抬升到下限。

## 快速开始

1. 下载 `index.html`，双击用 Chrome / Edge 打开（建议全屏、1920×1080 以上）。
2. 左侧「个人设置」依次填写：
   - **鼠标 DPI**：在鼠标驱动里读真实值；
   - **满腕程 W**：点「实测」，指针锁定后手腕不抬起推一次，按空格，工具自动算出 cm；
   - **可用垫宽**、**当前游戏内灵敏度**（填了它，推荐值会以你现有手感为锚，只做 ±12% 微调）。
3. 中间「瞄准测试」依次跑完 4 项：点开始 → 自动全屏 + 锁定指针 → 3 秒倒计时 → 正式开始。
4. 四项全部完成后，右侧自动生成灵敏度；底部「数值生成明细」逐行列出每一步算法。
5. 右侧「满腕程约束」区块显示校验结果：一屏对角线所需行程 vs 你的满腕程。

## 核心算法

### 1. 单位换算

```
eDPI    = DPI × 游戏内灵敏度
cm/360° = 360 × 2.54 ÷ (eDPI × 0.07)      Valorant 每 1 计数 = 0.07°
```

### 2. 光标映射（让测试手感 = 游戏内手感）

浏览器无法修改系统光标增益，因此测试使用 **Pointer Lock** 获取原始计数，自行积分虚拟准星：

```
px/计数 = 灵敏度 × 0.07° × (π/180) × (W/2) ÷ tan(103°/2) × 映射倍率
```

103° 是 Valorant 在 16:9 下的水平视野。注意用 `(W/2)/tan(hFov/2)` 而不是线性近似 `W/hFov`，后者会让灵敏度虚高约 40%。

屏幕缩放（devicePixelRatio）或系统指针加速造成偏差时，页面提供两种修正：

- **按屏幕缩放修正**：一键设为 `1/dpr`；
- **校准…**：用尺子在垫上量 10/20 cm 实测，自动反推倍率。

### 3. 满腕程约束（硬性）

```
一屏对角线 ≈ 110.5°（16:9）
要求： cm/360° × 110.5 ÷ 360 ≤ W
等价： cm/360° ≤ 3.258 × W
      eDPI ≥ 13062.9 × 110.5 ÷ (360 × W) ≈ 4010 ÷ W
```

| 满腕程 W | 约束下限 eDPI | 800 DPI 对应灵敏度 |
|---|---|---|
| 6 cm | 668 | 0.835 |
| 8 cm | 501 | 0.626 |
| 10 cm | 401 | 0.501 |
| 12 cm | 334 | 0.418 |
| 15 cm | 267 | 0.334 |

### 4. 合成顺序

```
① 基础 eDPI（手腕 380 / 混合 300 / 手臂 240）
② × 垫尺寸   ③ × 瞄准偏好   ④ × 手感反馈
⑤ 目标 eDPI
⑥ × 四项测试修正（0.85–1.15，带死区与无效样本剔除）
⑦ 基准 = 当前 eDPI × ⑥（未填当前值时用 ⑤ × ⑥）
⑧ 约束下限 = 4010 ÷ W
⑨ 合成 = max(⑦, ⑧)
⑩ 灵敏度 = ⑨ ÷ DPI，保留三位小数，限制 0.1–10
⑪ 约束校验
```

## 常见问题

**测试里光标比游戏内快 / 慢？**
先点「按屏幕缩放修正」（200% 缩放即 ×0.50）；仍不准就用「校准…」实测 10 cm。物理自检：800 DPI、灵敏度 0.375、1920 宽屏时，鼠标横移 1 cm ≈ 准星移动 110 px。

**跟枪测试总是跟不上、上靶率极低？**
把「满腕程」量准。工具会据此把目标振幅压到一次腕程可覆盖的范围内。若仍跟不上，通常说明 W 填大了，用「实测」重测（左右各测一次取平均）。

**推荐的灵敏度比我现在还低？**
旧版本的基础表（240–415 eDPI）会把你拽进区间。现版本已改为以当前灵敏度为锚，测试只做 ±12% 微调，并用满腕程下限兜底。请确认填写了「当前游戏内灵敏度」。

**为什么一定要全屏 + 锁定指针？**
全屏让像素与角度的换算等于真实显示器视野；指针锁定才能拿到未经系统加速的原始计数。两者缺一，映射都会失真，页面会提示「映射降级」。

**中途按 Esc 会怎样？**
释放指针 → 测试暂停，点「点击继续」重新锁定并继续；再按 Esc 退出全屏 → 本次测试中断、成绩作废。

## 已知限制

- 视野按 16:9 / 103° 水平换算；21:9、16:10 屏有约 ±5% 角度误差（可用映射倍率补偿）。
- 浏览器与系统差异（HiDPI、指针加速、驱动）需要一次校准，倍率保存在 localStorage。
- 测试场地有边界，准星到边即停（游戏内可无限转身），跟枪时请控制手部范围。
- 数值基于公开的 0.07°/计数 换算，与游戏实际手感可能存在个位数百分比差异，最终以靶场验证为准。
